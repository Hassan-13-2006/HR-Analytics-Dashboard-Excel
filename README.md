# HR Analytics Dashboard – Excel

## Project Overview
An HR Analytics Dashboard built using Microsoft Excel to analyze employee attrition and workforce trends. The project transforms HR data into meaningful insights using KPI cards, PivotTables, formulas, and charts.

## Dashboard Preview
(HR_Dashboard_Screenshot.png)

## Key Performance Indicators
- Total Employees
- Employees Left
- Attrition Rate
- Average Age
- Average Monthly Income
- Average Companies Worked

## Analysis Covered
- Attrition by Department
- Attrition by Job Role
- Attrition by Gender
- Attrition by Overtime
- Attrition by Job Satisfaction
- Attrition by Age Group
- Attrition by Business Travel
- Attrition by Work-Life Balance
- Attrition by Monthly Income
- Attrition by Education

## Tools Used
- Microsoft Excel
- Excel Tables and Formulas
- PivotTables
- Charts and Data Visualization

## Dataset
HR employee data containing 1,470 records and 22 original columns, with additional calculated grouping columns for analysis.

## Project Files
- `HR_Analytics_Dashboard.xlsx` — Excel workbook containing the data, analysis, PivotTables, and dashboard.
- `HR_Dashboard_Screenshot.png` — Dashboard preview.

## Objective
To identify employee attrition patterns and present workforce insights in a clear, professional dashboard.
